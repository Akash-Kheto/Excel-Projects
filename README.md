# 📊 Vrinda Store Data Analysis

## 📌 Project Overview

Vrinda Store Data Analysis is an Excel-based data analytics project created to analyze sales, orders, customers, order status, age groups, states, and sales channels.

The project includes an interactive Excel dashboard using PivotTables, PivotCharts, and Slicers.

## 🎯 Project Objectives

- Analyze monthly sales and orders
- Compare Men vs Women customers
- Analyze order status
- Identify Top 5 performing states
- Analyze orders by age group and gender
- Compare different sales channels
- Build an interactive Excel dashboard

## 📊 Dashboard Analysis

### 1. Order vs Sales
Monthly comparison of total sales amount and number of orders.

### 2. Men vs Women
Gender-wise analysis of customers/orders.

- Women: 64%
- Men: 36%

### 3. Order Status
Analysis of different order statuses:

- Delivered
- Refunded
- Returned
- Cancelled

### 4. Top 5 States
Sales performance analysis of the top 5 states.

### 5. Orders: Age vs Gender
Comparison of orders across:

- Adult
- Senior
- Teenager

with a Men vs Women breakdown.

### 6. Channel Analysis
Sales/order contribution across different channels:

- Amazon
- Flipkart
- Myntra
- Ajio
- Meesho
- Nalli
- Others

## 📈 Key Insights

- Women represent a larger share than men in the dashboard.
- Delivered orders form the majority of orders.
- Maharashtra is one of the top-performing states.
- Amazon has the highest channel contribution shown in the dashboard.
- Monthly sales and order volumes vary throughout the year.
